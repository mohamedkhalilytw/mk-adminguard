Privacy Policy — MK AdminGuard

Last updated: November 2026 Publisher: Mohamed Khalil MK ("we", "us") Contact: mohamedkhalilytw@gmail.com

In short

  • MK AdminGuard has no account, no telemetry, no analytics and no ads.
  • Your Meraki API key is never saved. It is kept in memory while the app is open.
  • The information the app handles goes only to Meraki, at your request. We do not receive any of it.

Personal information the app handles

  • Meraki API key — you type it into the app.
  • Administrator information read from Meraki: organization names and IDs, and administrator names, email addresses, access levels, two-factor-authentication status and last-activity dates. These are personal details of your colleagues or customers.
  • Information you enter: the names and email addresses of administrators you want to add or remove, including those you import from a CSV file.

How it is used, stored and secured

  • Use. The information is used only to do what you ask: list organizations and administrators, add, update or remove administrators, and show results.
  • In transit. Everything sent to Meraki goes over HTTPS (encrypted) to the Meraki Dashboard API (api.meraki.com).
  • API key. Kept in memory only while the app is open. It is never written to disk, to the log, or to any file you export, and it is hidden from error messages.
  • Operation log. When you run an operation (add, remove, update, undo), the app saves a log entry on your PC with: date and time, the type of operation, whether it was a dry run, the organization name and ID, the administrator email, and the result or error message. Every entry is encrypted with Windows data protection (DPAPI), which ties it to your Windows user account, and is kept in the app's private storage. The log never contains the API key.
  • Files you export. A log or audit file that you export is a normal CSV file stored where you choose; you control it. The app neutralises characters that could trigger spreadsheet formulas.
  • Demo mode. If you type DEMO as the API key, the app uses built-in sample data and makes no connection to Meraki.

Who receives information

  • Cisco Meraki — when you run an operation, the administrator names, email addresses and access levels you entered are sent to the Meraki Dashboard API of the organizations you selected. Cisco's own terms and privacy notices apply to that service.
  • Us (the publisher) — nothing. The app contains no code that sends data to us, and we operate no servers for it.
  • Microsoft — the app is distributed through the Microsoft Store. Microsoft handles purchase, installation and its own diagnostic data under the Microsoft privacy statement. We may see aggregated sales and crash reports in Partner Center, which do not include the information described above.
  • We do not sell, rent or share information with advertisers or data brokers.

Your controls and access to your information

  • You decide which information to enter, which organizations to select and whether to run an operation. Dry run previews a change without making it, and Undo reverses the last operation.
  • View or export the operation log: About → Export Operation Log.
  • Delete the operation log: About → Clear Operation Log. Uninstalling the app also removes it.
  • Revoke the API key at any time in the Meraki dashboard (My profile → API access). Manage administrators directly in the Meraki dashboard.

Information about other people

Administrator names and email addresses belong to other people. You are responsible for having the right, and any consent the law requires, to view them and to submit them to Meraki, and for informing those people where required.

Retention

The only information stored by the app is the encrypted operation log. It stays until you clear it or uninstall the app.

Children

The app is intended for IT professionals and is not directed to children.

Changes

If this policy changes, the new version will be published at the same address and in the app, and the "Last updated" date will change.
